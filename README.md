# Todo List App 📝

A simple and interactive Todo List application built using HTML, CSS, and JavaScript. Users can add, complete, and delete tasks. Tasks are saved in Local Storage, so they remain available even after refreshing the page.

## 🚀 Live Demo

[View Todo List App](https://to-do-list-five-umber-16.vercel.app)

## ✨ Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- Save tasks using Local Storage
- Maintain tasks after page refresh
- Dynamic task updates

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Local Storage
- JSON

## 📌 How to Run Locally

1. Clone this repository:
   `git clone YOUR_GITHUB_REPOSITORY_URL`
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
